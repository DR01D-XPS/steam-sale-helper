Steam Sale Helper 0.1.5 - готовая папка расширения

Что исправлено:

- Календарь распродаж полностью локальный, из src/data/sales-calendar.seed.json.
- Если SteamDB не отдал данные, расширение все равно показывает ближайшую крупную распродажу из локальной базы.
- Старый provider mock принудительно отключается в обычном режиме, чтобы не было выдуманных цен.
- Текущая цена со скидкой используется как начальная цена для расчета.
- Если скидка уже действует, карточка пишет, что сейчас выгодная цена.

Как обновить:

1. Откройте chrome://extensions
2. Удалите старый Steam Sale Helper.
3. Распакуйте новый zip.
4. Нажмите "Загрузить распакованное расширение".
5. Выберите папку Steam-Sale-Helper-0.1.5-ready.
6. На карточке расширения должна быть версия 0.1.5.
7. Обновите https://store.steampowered.com/cart/

Календарь обновлять вручную один раз в год в src/data/sales-calendar.seed.json,
а затем пересобирать расширение.
