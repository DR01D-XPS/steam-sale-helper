Как установить:

1. Открой Chrome: chrome://extensions
2. Включи "Режим разработчика".
3. Нажми "Загрузить распакованное расширение".
4. Выбери папку Steam-Sale-Helper-0.1.6-ready.
5. Открой корзину Steam: https://store.steampowered.com/cart/

Если расширение уже было установлено:
1. Удали старую версию.
2. Загрузи папку Steam-Sale-Helper-0.1.6-ready заново.

Где обновлять данные:
- Календарь распродаж: src/data/sales-calendar.seed.json
- Ручная база скидок: src/data/discounts.seed.json
