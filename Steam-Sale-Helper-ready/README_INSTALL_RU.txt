Steam Sale Helper - готовая папка расширения

Как установить без консоли:

1. Скопируйте эту папку на компьютер.
2. Откройте Chrome или Chromium-браузер.
3. Перейдите на страницу chrome://extensions
4. Включите "Режим разработчика" / Developer mode.
5. Нажмите "Загрузить распакованное расширение" / Load unpacked.
6. Выберите именно эту папку: Steam-Sale-Helper-ready.
7. Откройте https://store.steampowered.com/cart/

Если до этого была старая версия:

1. Нажмите "Удалить" у старого Steam Sale Helper.
2. Загрузите новую папку заново через "Загрузить распакованное расширение".

Важно:

- Папку нельзя удалять после установки: Chrome читает расширение прямо из нее.
- Консоль, npm и сборка не нужны.
- Если отправляете zip, сначала распакуйте его, затем выберите распакованную папку.
- Для обычной установки в один клик нужна публикация в Chrome Web Store. Без магазина Chrome устанавливает такие расширения через Load unpacked.
