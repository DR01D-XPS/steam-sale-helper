Steam Sale Helper 0.1.3 - готовая папка расширения

Исправление бага:

- Названия распродаж теперь берутся в русском виде из руководства Steam 2026.
- Ближайший "Фестиваль «Играм быть» 2026" больше не выбирается вместо "☀️ Летняя распродажа", если нет данных именно по фестивалю.
- Mock provider больше не включен по умолчанию, потому что он может давать игрушечные цены вроде 70 ₸.
- Слишком маленькая низкоуверенная цена не используется в зеленой сумме корзины.

Как обновить:

1. Откройте chrome://extensions
2. Удалите старый Steam Sale Helper.
3. Распакуйте новый zip.
4. Нажмите "Загрузить распакованное расширение".
5. Выберите папку Steam-Sale-Helper-0.1.3-ready.
6. На карточке расширения должна быть версия 0.1.3.
7. Откройте настройки расширения и убедитесь, что provider = steamdb, а не mock.
8. Обновите страницу https://store.steampowered.com/cart/

Если расширение не может получить данные SteamDB, оно должно использовать текущую цену,
а не выдумывать прогноз из mock-данных.
