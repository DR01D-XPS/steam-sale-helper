Steam Sale Helper 0.1.1 - готовая папка расширения

Если раньше была ошибка "Cannot use import statement outside a module":

1. Откройте chrome://extensions
2. Нажмите "Удалить" у старого Steam Sale Helper.
3. Распакуйте новый zip.
4. Нажмите "Загрузить распакованное расширение".
5. Выберите папку Steam-Sale-Helper-0.1.1-ready.
6. На карточке расширения должна быть версия 0.1.1.
7. Откройте https://store.steampowered.com/cart/

Важно:

- Не выбирайте старую папку Steam-Sale-Helper-ready, в ней у друга мог остаться старый content/index.js.
- Папку нельзя удалять после установки: Chrome читает расширение прямо из нее.
- Консоль, npm и сборка не нужны.
- Если отправляете zip, сначала распакуйте его, затем выберите распакованную папку.
