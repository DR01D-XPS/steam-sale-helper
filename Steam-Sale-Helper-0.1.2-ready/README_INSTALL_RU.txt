Steam Sale Helper 0.1.2 - готовая папка расширения

Что изменилось:

- Исправлен запуск content script без ESM import.
- Добавлен парсер новой корзины Steam.
- Добавлена видимая диагностическая плашка, если расширение запустилось, но товары не найдены.

Как обновить:

1. Откройте chrome://extensions
2. Удалите старый Steam Sale Helper.
3. Распакуйте новый zip.
4. Нажмите "Загрузить распакованное расширение".
5. Выберите папку Steam-Sale-Helper-0.1.2-ready.
6. На карточке расширения должна быть версия 0.1.2.
7. Обновите страницу https://store.steampowered.com/cart/

Если на странице появится плашка "extension is running, but cart items were not detected",
значит расширение установлено правильно, но Steam выдал еще один вариант DOM. Тогда нужно прислать
скрин этой плашки и, желательно, HTML одного товара из DevTools.
